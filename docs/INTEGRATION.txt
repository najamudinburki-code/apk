Required existing-app integration
The services preserve the existing opt-in ParentalCapture gate. They will not
emit JSON until the app supplies an approved-package set and an in-process
JSON consumer. Connect the following calls to your existing visible consent
and Stop actions, on the main thread:

Start, after the user approves the packages:
    ParentalCapture.onJson = yourExistingJsonConsumer
    val enabled = ParentalCapture.enable(this, yourApprovedPackages)
    // Handle enabled == false in your existing UI.

Stop:
    ParentalCapture.disable(this)

The two names above refer to values supplied by your app, not provided APIs.
The existing System Health Start/Stop buttons in CoreService.kt do not perform
this parental-capture initialization. Android accessibility and notification
access must also be enabled by the device user in Settings.

No upload endpoint, persistent text storage, or new monitoring feature is added.
